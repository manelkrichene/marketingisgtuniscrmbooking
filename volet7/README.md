# Volet 7 — Landing pages B2C & B2B

Projet académique CRM / HubSpot — ISG Tunis.

## Pages
- `/travel-personality.html` — quiz B2C Find Your Travel Personality.
- `/partners.html` — qualification B2B Become a Partner.
- `/` — index des deux parcours.

## Design
Palette cohérente avec les emails du Volet 3 : #003B95, #0071C2, #FEBB02, #F2F6FA, #172B4D, #1A1A1A. Responsive, HTML/CSS/JS sans dépendance payante.

## CRM
Les formulaires utilisent des attributs name correspondant aux propriétés HubSpot existantes ou ajoutées dans le Volet 7. Pour que le tracking collecte les formulaires HTML externes, activer dans HubSpot le paramètre de collecte des formulaires externes (Collect data from website forms) et vérifier le domaine autorisé. Les formulaires ne sont pas des formulaires HubSpot natifs; le portail ne disposait d'aucun formulaire natif adapté et l'API connectée n'autorise pas la création de FORM.
